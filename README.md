# ProgressAI

See [`backend/README.md`](backend/README.md) for the full setup guide.

- `frontend/` — supplied HTML/CSS visual design plus API-integrated vanilla JS.
- `backend/` — FastAPI, async PyMongo, JWT/password hashing, task history, analytics, ML demo pipeline, notifications.

Start MongoDB, configure `backend/.env`, run FastAPI from `backend/`, and serve `frontend/` using a local HTTP server.
